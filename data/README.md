# data/

`developer-contract.json` is a copy of `tests/fixtures/developer-contract.json` in
[dealdeskco/dealdesk](https://github.com/dealdeskco/dealdesk): the public developer contract (every
REST endpoint with its scope, and every MCP tool with its inputs), generated by the app's own tests.

`scripts/check-developer-contract.mjs` runs before every build and fails it if an endpoint or a
tool in this file is missing from the developer docs in any locale. When the app's contract
changes, copy the new file here and document what changed:

```bash
git -C ../dealdesk show origin/main:tests/fixtures/developer-contract.json > data/developer-contract.json
```
